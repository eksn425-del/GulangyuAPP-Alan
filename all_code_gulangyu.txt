1. 项目定位
本仓库是整个“听见·鼓浪屿”APP 的 Web 端与主业务后端，负责真实用户交互、建筑数据管理、AI 导览编排、无障碍路径计算，以及与 Unity 3D 仿真端的数据闭环。

当前代码库中的核心职责分为四层：
- 前端展示层：React + Vite + Tailwind 风格类名
- 业务接口层：FastAPI
- 数据层：SQLite + SQLAlchemy + 原始内置数据
- 算法与AI层：多路径寻路、中文地名容错识别、DashScope 大模型调用

本仓库不是单纯官网，也不是单纯管理后台，而是“用户体验入口 + 导览大脑 + 数据中台”。

7. 路径算法当前实现
================================================================================
7.1 原始数据来源
- database.py 中内置 buildings_data、nodes_data、roads_data
- init_db() 会创建表并清空后重新写入这些内置数据

7.2 图构建方式
- graph_engine.py 从 SQLite 读取节点与道路
- 使用 NetworkX Graph 建图
- 节点属性含名称、经纬度、类型、detail
- 边属性含 distance、slope、friction、material、note

7.3 距离与方向计算
- 距离：Haversine 公式
- 绝对方向：calculate_bearing()
- 相对转向：
  - get_relative_turn()
  - get_turn_instruction()

7.4 权重模型
calculate_edge_weight(distance, slope, friction, user_type)
根据用户类型差异化设置权重参数：
- normal
- elderly
- disabled
- blind

其中权重由三部分组成：
- 距离成本
- 坡度成本
- 摩擦/防滑成本

7.5 多路径生成
- 使用 shortest_simple_paths 生成候选路径
- 通过边重叠率筛掉过于相似的路线
- strategy 支持：
  - safest：按综合安全权重
  - shortest：按纯距离

7.6 建筑入口接边逻辑
- 所有“建筑入口”节点会动态连接到最接近的道路边两端
- 这样建筑入口与普通路口可以形成可达路径

8. AI 对话与意图识别当前实现
================================================================================
8.1 模型调用
- 文本对话：qwen-turbo
- 图像理解：qwen-vl-max

8.2 /api/chat 的处理流程
1) 接收 message、user_bearing、asr_confidence、strategy、test_mode
2) 读取实时建筑与节点数据
3) 识别是否存在导航意图
4) 对建筑名进行中文别名、拼音、模糊匹配
5) 推断起点与终点
6) 调用 route_engine.get_safest_route()
7) 将路线结果写入系统提示词
8) 调用大模型输出面向视障用户的话术

8.3 地名容错识别机制
当前后端并不是简单字符串相等匹配，而是混合使用：
- PLACE_ALIASES：手工别名表
- PLACE_PINYIN：标准拼音
- PLACE_PINYIN_PREFIX：拼音前缀
- fuzzy_substring_match / fuzzy_substring_details：模糊窗口匹配
- adaptive_match_threshold：按短词与 ASR 置信度调整阈值

8.4 导航回答约束
- 路线播报禁止使用东南西北
- 优先使用左转、右转、直行等相对方向
- 当系统已确定起终点时，会把纠错结果强行写入 prompt，减少模型“没听清”的回答

12. 与 Unity 项目的关系
================================================================================
本仓库与 e:\Gulangyu_3D 的关系是：
- 本仓库负责真实业务接口、AI、数据库、路径算法
- Unity 仓库负责 3D 数字孪生仿真、盲杖探测、危险触发、A/B 实验代理
- Unity 的 A/B 与 hazard 数据回流到本仓库
- 本仓库的 /api/route 又反向为 Unity 的 B 组 safest 导航提供路线

因此二者不是“谁附属谁”的关系，而是：
- Web/Backend 是业务中台与用户交互中枢
- Unity 是 3D 仿真与实验验证终端
