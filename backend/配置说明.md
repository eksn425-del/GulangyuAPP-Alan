# API Key 配置说明

## 方式一：使用环境变量（推荐）

### Windows PowerShell:
```powershell
$env:DASHSCOPE_API_KEY="sk-your-api-key-here"
```

### Windows CMD:
```cmd
set DASHSCOPE_API_KEY=sk-your-api-key-here
```

### Linux/Mac:
```bash
export DASHSCOPE_API_KEY=sk-your-api-key-here
```

## 方式二：使用 .env 文件（推荐用于开发）

1. 在 `backend` 目录下创建 `.env` 文件
2. 添加以下内容：
```
DASHSCOPE_API_KEY=sk-your-api-key-here
```

3. 安装 python-dotenv（如果还没有安装）：
```bash
pip install python-dotenv
```

## 注意事项

- 如果既没有设置环境变量，也没有 `.env` 文件，代码会使用默认值（仅用于开发测试）
- **生产环境请务必使用环境变量或 .env 文件，不要将 API Key 硬编码在代码中**
- `.env` 文件已被 `.gitignore` 忽略，不会被提交到 Git
